Amazon Redshift solves the problem of **operational databases grinding to a halt when data analysts run massive query reports.** If you try to run a multi-year financial trend analysis on your live transactional production database, the application will crash. Redshift is a fast, petabyte-scale data warehouse that uses columnar storage and massively parallel processing (MPP) to analyze vast amounts of historical data without impacting your day-to-day application performance.
