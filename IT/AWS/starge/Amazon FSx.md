Amazon FSx solves the problem of **running specialized or legacy enterprise file systems in the cloud**.

- **FSx for Windows File Server:** Solves the problem of migrating old Windows apps that rely on native SMB protocols and NTFS permissions.
- **FSx for Lustre:** Solves the problem of **slow processing for high-performance computing (HPC)** workloads like machine learning, financial modeling, or weather forecasting that require lightning-fast parallel file processing.
