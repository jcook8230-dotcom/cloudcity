AWS organizes its extensive portfolio of over 200 services into clear, logical functional groups. These **major AWS service categories form the building blocks of cloud architecture**, allowing organizations to assemble and scale complete digital platforms on demand.

---

1. Compute Services

Compute resources provide the processing power, memory, and runtime environments required to execute application code and host operating systems.

- **[Amazon EC2 (Elastic Compute Cloud)](https://aws.amazon.com/ec2/):** Secure, resizable virtual servers that give users full administrative control over the operating system.
- **[AWS Lambda](https://aws.amazon.com/lambda/):** A serverless compute service that runs code purely in response to triggers and events, automatically scaling down to zero when idle.
- **[Amazon ECS](https://aws.amazon.com/ecs/) & [Amazon EKS](https://aws.amazon.com/eks/):** Highly scalable container management systems used to run, orchestrate, and deploy Docker and Kubernetes containers.

2. Storage Services

AWS offers distinct storage types tailored for different data access speeds, structures, and retention requirements.

- **[Amazon S3 (Simple Storage Service)](https://aws.amazon.com/s3/):** An object storage service built to store and protect any amount of unstructured data (such as images, videos, or backups) with 99.999999999% durability.
- **[Amazon EBS (Elastic Block Store)](https://aws.amazon.com/ebs/):** High-performance block storage volumes designed to act as the primary, persistent hard drives for EC2 instances.
- **[Amazon EFS (Elastic File System)](https://aws.amazon.com/efs/):** A serverless, fully managed file share system that can be mounted simultaneously by multiple virtual machines.

3. Database Services

Instead of manually managing database engines on virtual servers, AWS provides fully managed, automated database options.

- **[Amazon RDS (Relational Database Service)](https://aws.amazon.com/rds/):** Simplifies the setup, operation, and scaling of traditional relational databases like MySQL, PostgreSQL, and SQL Server.
- **[Amazon DynamoDB](https://aws.amazon.com/dynamodb/):** A fully managed, serverless NoSQL database service that provides consistent, single-digit millisecond latency at any scale.
- **[Amazon Aurora](https://aws.amazon.com/rds/aurora/):** A cloud-native, high-performance relational database engine designed to combine the speed of commercial engines with the open-source simplicity of MySQL and PostgreSQL.

4. Networking and Content Delivery

These services isolate cloud resources, protect connections, and route user traffic efficiently around the globe.

- **[Amazon VPC (Virtual Private Cloud)](https://aws.amazon.com/vpc/):** A logically isolated virtual network where you control your own IP address ranges, subnets, routing tables, and network gateways.
- **[Amazon Route 53](https://aws.amazon.com/route53/):** A highly available and scalable cloud Domain Name System (DNS) web service that routes end-user requests to internet applications.
- **[Amazon CloudFront](https://aws.amazon.com/cloudfront/):** A fast Content Delivery Network (CDN) that securely delivers data, videos, and applications to global users with low latency using edge locations.

5. Management, Governance, and Security

Tools designed to track resource usage, manage user access permissions, control spending, and secure applications.

- **[AWS IAM (Identity and Access Management)](https://aws.amazon.com/iam/):** The core security service used to securely manage fine-grained access permissions to AWS resources and APIs.
- **[AWS CloudTrail](https://aws.amazon.com/cloudtrail/):** Tracks user activity and API usage across your entire AWS infrastructure to simplify security auditing and compliance.
- **[Amazon CloudWatch](https://aws.amazon.com/cloudwatch/):** A comprehensive monitoring and observability service providing real-time data and actionable insights on infrastructure health and performance.

6. Artificial Intelligence (AI) and Machine Learning (ML)

AWS offers fully managed AI infrastructure and developer frameworks to quickly build and scale modern intelligent applications.

- **[Amazon SageMaker](https://aws.amazon.com/sagemaker/):** A fully managed service that provides developers and data scientists with the ability to build, train, and deploy custom machine learning models at scale.
- **[Amazon Bedrock](https://aws.amazon.com/bedrock/):** A serverless service that makes foundation models (FMs) from leading AI companies accessible via an API, allowing teams to build secure generative AI applications.
